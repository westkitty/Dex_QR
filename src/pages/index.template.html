Send a file through your screen.

Dex_QR turns any file into an animated stream of QR codes. Point another device's camera at it and the file rebuilds there. No Wi-Fi, no cables, no accounts, and no network at all.

Send a file On the device that has it Receive a file On the device with the camera

1 Pick a file

Open the sender on the device that has the file, and add an optional passphrase to encrypt it.

2 Show the stream

The sender plays a fountain of QR codes. The receiver can miss frames or start late: any frames will do.

3 Scan and save

Open the receiver on the other device, point its camera, and save the file once it is checked.

Both pages are single self-contained HTML files. Save them and open them from disk (file://); a Content-Security-Policy blocks every network connection. Real phone and laptop camera scanning has not been tested by the author yet; see docs/TEST_CHECKLIST.md in the repository.
